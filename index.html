Формулы Excel — ABC по выручке

Шаг 1. Сортировка: «Данные» → «Сортировка» → по «Выручка» → «от Я к А».
Шаг 2. Доля, %: =B2/СУММ($B$2:$B$20)*100
Шаг 3. Накопительная: первая ячейка =C2, ниже =D2+C3
Шаг 4. Группа: =ЕСЛИ(D2<=80;"A";ЕСЛИ(D2<=95;"B";"C"))
№ Наименование Выручка, ₽ Доля, % Накопит. доля, % Группа 🔍
A — до 80 % B — 80–95 % C — свыше 95 %

Формулы Excel — ABC по остаткам

Шаг 1. Сортировка: «Данные» → «Сортировка» → по «Остаток» → «от Я к А».
Шаг 2. Доля, %: =B2/СУММ($B$2:$B$20)*100
Шаг 3. Накопительная: первая ячейка =C2, ниже =D2+C3
Шаг 4. Группа: =ЕСЛИ(D2<=80;"A";ЕСЛИ(D2<=95;"B";"C"))
№ Наименование Остаток, ₽ Доля, % Накопит. доля, % Группа 🔍

🔀 Матрица «Продажи × Остатки»

⚠️ A×A — затоваривание
🔴 C×A — мёртвый груз
🟡 B×A — перезаказ
🟡 C×B — сократить
🟢 A×B, A×C, B×B,
B×C, C×C — норма
